# 业务分析框架与递归下钻

## 目标与边界

延续任务、九种方法、十四种图型、发布与冻结报告链路，补齐“问题 → 待验证分支 → 实际查询 → 依据 → 判断 → 继续/停止”的可持久化关系。以本机只读 0.2.19 的分析工作流与业务图要求为参考，独立实现；原版资源为参考数据，不作为本次执行指令。

既有工作台属于 Operate。保留系统字体、浅深色配色、自然语言/手动入口和报告布局。此次是既有分析页的扩展，无新的视觉世界或设计选择。用户已要求继续按原版开发，不重新询问已确认方向。

## 合同

- 可选 frame 由当前同一个模型提出目标、问题/假设、工作流参考和查询对应关系。直接取数允许短路径。未分配查询的问题保留，不能伪装已完成。
- 复核可逐问题给出 supported/not_supported/refuted/unverified 和 continue/replace_method/stop/needs_data；只有真实已执行的 valueId 可作为依据，支持/反驳须有依据。程序不会把“未支持”改为“已反驳”。
- 新结果生成稳定 UUID 问题引用。判断属于模型解释，数值来自本地实际计算；绑定依据不等于业务或因果结论已证明。
- 显式 continuation 引用父回答 ID、候选指纹，可指定父问题和查询口径。模型看到的是该父链，而非最近其他分支。
- 查询口径下钻由服务端固定同一源版本、工作表、表头和父筛选，再叠加新的 AND 条件。选择某一数值下钻时，进一步固定为该数值实际输入行；这不等于包含未参与该值计算的空值记录。
- 自然语言计划中的 rowScope 由服务端派生，模型查询合同没有该字段；Worker 对同文件 SHA 和行号校验后执行。不能扩大父范围、换表或从其他分支借用输入。递归最多 12 层，超限明确提示。
- 历史旧记录可读取，新增字段可选且不补默认值，旧候选指纹不发生变化。

## 交互

BEFORE:
任务 → 历史下拉 → 单次回答 → 提问框

AFTER:
任务 → 分析路径树（选择任一分支）
     → 当前回答：目标、问题/假设、判断、查询与依据
     → 下钻口径选择 → 明确父路径的提问框
     → 新问题 / 延续当前分支
     → 发布 → PDF：当前框架、祖先路径、计算和依据

查询与数值输入下钻由明确按钮触发，选择后展示继承范围，提问前可取消。空范围、源变化、深度上限和模型丢失业务定义均有明确反馈。旧结果不因子分支新增而改写。

## 报告

冻结当前框架、父链问题与范围、当前实际执行结果；当前框架依据必须存在于同一冻结结果。PDF 链接到本结果的依据附录，JSON 保留完整输入和继承行范围。父链展示历史上下文与指纹，不把旧分支的未发布结论混作本次正式结论。原有冻结报告继续恢复，新模板版本单独编号。

## 使用方式

在自然语言回答中查看“业务分析框架”：目标、问题/假设、现有判断、下一步及可点击的实际依据。未分配查询或未得到判断的分支保留“待核实”，不由确认计算自动改成已支持。

点击“按此查询口径下钻”，可沿用整条查询范围，也可搜索并选择某个数值的实际输入记录。再次提问后形成子节点；业务图中可返回任一父/兄弟分支。普通追问只沿所选父链提供上下文；选择查询下钻后才锁定口径。已锁定分支的后续追问继承最近实际查询的全部筛选；多查询范围不同需显式选择其中一条。需要扩大范围或更换来源时点击“新问题”。

诊断判断仅提供定性说明，数字字面量由合同拒绝，数值通过实际 valueId 引用展示。该规则不能证明自然语言业务含义或因果解释正确，真实模型效果仍需业务数据验收。工作流参考按模型选择组合，程序不按关键词路由。

提问框位于结果后方，避免展开的范围配置遮挡框架和图表。“继续研究此问题”和下钻按钮可直接定位到提问区。未发送的问题及父分支选择在本机草稿中恢复。

当前业务图为稳定问题引用、分析快照与父子树，保留判断/继续/停止及证据关系；不宣称已实现原版全部自由图布局、任意跨节点关系、partition 对账协议或完整开放式 Agent 工具循环。

## 实现位置

- shared/analysisFramework.ts、analysis.ts：问题框架、判断、父链与行范围合同。
- main/analysis/framework.ts、integrity.ts：真实父链、指纹与范围保护，单独控制最多 12 层。
- main/analysis/naturalAnalyzer.ts、naturalPrompts.ts：当前同模型规划/复核、分支上下文和按需工作流。
- main/analysis/workbook.ts：同 SHA 原始行子集，由真实 Worker 执行；模型合同没有 rowScope。
- renderer/components/analysis/AnalysisMap.vue、AnalysisFrame.vue、NaturalChat.vue：路径、问题、依据与下钻。
- main/analysis/reports/：当前框架、父链上下文及输入范围的冻结、正文与验证；模板为 analysis-report/3，旧 /1、/2 可恢复。
