# 任务引导、数据引用、文字追问与状态恢复

目标基线 SemaPath 0.2.19。本轮对照本地已审计的 GettingStartedPage／ChatTabView：五类引导（model、task、data、file、advanced）、离线 80／100／20 示例、`@` 数据结构候选、为什么／拆开看／纠正口径三种文字追问、2000 字选区限额，以及面板恢复。原版与用户配置只读，不启动原版或显示验证窗口。

## 设计与数据边界

- 在既有工作台中加入可续接引导，并提供 `/getting-started` 入口。模型、数据与成果状态来自实际配置和当前任务；离线示例明确标为示例，不登记成用户分析或假装已配置模型。
- 数据引用使用当前任务已登记的文件及已绑定 MySQL／Power BI 结构。表和字段绑定来源、工作表／表名、物理列／字段名及结构指纹；度量只来自模型的真实 measure 元数据，不把任意数值列冒充度量。不申请新的连接权限。
- 选中的引用由主进程保存为不透明 context ID。编辑器、草稿、排队消息和消息正文保留结构化引用；主进程在发送时校验归属和当前版本。模型通过现有 `analysis_get(contextId)` 读取可信的结构及来源，前端标签不是数据依据。查询和正式发布继续遵守已有来源／版本约束。
- 文字追问保存选中文字、所属回答或消息、原版本与归一化位置。主进程核对文字属于实际保存内容；引用不作为新的计算依据。历史引用保留当时文字，原文改变或消失时明确标记，不能静默指向别的回答。
- 每个任务独立保存活动视图、数据／计算选择、展开状态、滚动位置及可恢复的聊天侧面板设置；引导单独保存进度。只保存界面状态，不在恢复时重新取数、计算或申请权限。失效 ID、损坏版本和越界尺寸安全回退；异步切换不得覆盖另一任务。
- 复用既有聊天输入、草稿和消息运行时。外部 ACP Agent 的专用分析工具调用保持已有边界，不以通用聊天底座冒充已接入。

## 界面变化

BEFORE:
工作台 → 每次选择重置面板；输入 @ 仅搜索文件；文字追问无原文引用

AFTER:
工作台／上手入口 → 五类引导 → 同一任务与真实配置
任务对话 @ → 来源／表／字段／度量 → 结构化引用与版本检查
回答文字选区 → 为什么／拆开看／纠正口径 → 可回查的引用草稿
切换／重启 → 按任务恢复面板、选择和草稿 → 失效时明确回退

保持既有蓝色、浅深主题、字体和线性布局；属于已明确要求的局部扩展，不做新的视觉方向或设计系统迁移。界面与验证记录放在各自规定目录，自动化保持隐藏、不可聚焦，不调用真实外部浏览器或文件查看器。

## 与现有设计系统的对照

| 现有约束 | 本轮实际实现 |
|---|---|
| 工作台蓝色与浅深主题 | 保留浅色 `#2364ca`、深色 `#85b4ff` 及既有背景、前景、边线、悬浮层变量；引导说明和引用元数据继续以主题前景／背景混合生成次要文字。 |
| 现有字体与紧凑层级 | 继承应用的 `--dc-font-family`，不另设字体。工作台与详情正文为 13px，标签和选区工具条为 12px；引导内部使用 24／18／15px 标题，详情标题为 16px，均限于对应组件。 |
| 左侧任务、右侧线性工作区 | 保留应用栏、任务列表、数据入口和页签；引导嵌入原工作台。引用详情宽 340px、最多占对话区 50%，与聊天侧面板互斥；普通聊天侧面板最多占 52%，窄聊天区的状态控件按可用宽度换行。 |
| 留白、细分隔线与既有控件 | 引导按可展开的线性条目组织，引用以小标签和可回查详情呈现；沿用 shadcn-vue 按钮和 Lucide 图标。选区工具条复用悬浮层主题并局部使用柔和投影，其形状与投影不提升为新的全局规则。 |
| 清楚的焦点、加载、失败与恢复状态 | 保留可见焦点；引用和引导以文字表达状态。数据引导按实际结构目录区分检查中、已就绪、部分可用和暂不可用，并可重新检查；文件状态独立判断，所以只有可用数据库绑定时，数据可就绪而任务文件仍待完成。 |

本轮是现有系统的局部扩展，根 `DESIGN.md` 与 `PRODUCT.md` 保持原状；表面方向与已实现范围记录在 `.impeccable/surfaces/src-pages-analysis-analysisworkbench-vue-346b16fb.md`。新增交互组件不使用新的出货位图资源。
