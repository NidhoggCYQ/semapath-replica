# 已发布回答、报告与成果

## 当前可用路径

在分析工作中核对数据依据并发布回答，点击“生成 PDF 报告”；也可进入“报告与成果”，选择一个已发布版本。支持完整自然语言回答和单次手动计算，未发布草稿不能生成报告。

填写标题，选择 A4 阅读 PDF 或 16:9 演示 PDF、简体中文或英文，点击“生成 PDF”。生成完成后可预览、另存 PDF、打开所在文件夹或另存数据依据 JSON。16:9 输出是固定版式 PDF。

报告包含本次结构化视图中的结果、排名、占比/比较、图表、完整精确结果表、计算口径、文件指纹及依据附录。PDF 中的 [E1.1]、[D1] 等引用可跳转到对应依据；需要完整行级输入时另存 JSON，里面保留本次计算使用的行号、单元格、输入值和计划。PDF 附录只展示输入单元格定位示例，明确标注完整输入见 JSON。原工作簿由文件指纹标识，不嵌入报告。

## 冻结与版本规则

- 导出只读取已发布记录，不请求模型或重新读取当前 Excel。文件后来修改、移走、删除，仍可导出发布时的历史依据。
- 创建报告时校验候选 hash、全部关联运行和正式状态，冻结结构化数据与编译后的 HTML，并分别记录 SHA-256。原生文件路径不进入冻结 JSON。
- 同一回答、标题、格式、语言及渲染版本可复用已有成功报告；请求 ID 重复不会重复创建成果。
- “重新生成”或失败重试使用该报告原有的冻结 JSON 与 HTML，不套用当前 Excel 的新数据。生成次数及失败/取消状态分别留档。
- 报告、冻结内容和尝试记录跟随独立应用配置目录持久化。应用启动时将未结束尝试标为中断；用户可从原冻结内容重试。
- 打开、保存前重新核对文件 hash。受损或缺失 PDF 不能当作成功成果打开；PDF 本体受损而冻结内容完好时，可重新生成。冻结文件本身受损时应从已发布回答生成新报告。

## 实现

共享契约在 `src/shared/analysisReport.ts`；报告的类型化 IPC 合并在 `src/shared/contracts/routes/analysis.routes.ts`，仅允许可信界面调用。界面不提供任意输入或输出文件路径参数，保存位置通过原生文件对话框选择。

报告服务为 `src/main/analysis/reports/service.ts`，使用独立 SQLite 表 `replica_analysis_reports` 保存元数据，不回写分析任务 JSON，避免与正在进行的分析覆盖彼此状态。数据冻结和引用校验在 `snapshot.ts`；结构化正文、条形图/折线图及表格编译在 `document.ts`。

`nativeRenderer.ts` 使用隐藏 Chromium 窗口，禁用 Node 和 WebView，启用隔离与沙箱；一个内存 Session 按 WebContents 分别限制可读取的冻结文档，拒绝其他文件和网络请求。正文数据全部转义，不加载远程字体或执行用户 HTML/脚本。当前版本只运行应用自有编译器，不支持任意 Python/HTML builder。

布局先检查横向溢出与超过页面高度的不可分块元素，再生成 PDF。`analysisReportWorkerEntry.ts` 在独立 Worker 中提取全部页面文字、核对实际纸张尺寸、精确值与带边界的依据标记。只有核对完成、PDF 原子落盘且 hash 一致才标记为“PDF 已就绪”。后台生成可取消，来源窗口销毁或应用退出时会清理任务。

## 当前边界

- 默认报告沿用工作台的蓝白简洁风格，提供 A4 和 16:9 两个页面格式及中英文固定文案。原版 9 种视觉方向、5 个原型、业务/技术读者模板和自定义 builder 尚未对齐。
- 基础汇总仍为条形、折线和表格；方法分析已接入九种方法与十四种图型，界面和 PDF 共用数据绑定及图形编译器，保留方法条件、自检、精确表和公式。完整范围见 [分析方法与图表](methods-and-charts.md)。较多分组会分段绘图，不截取前几组代替全量结果。
- 报告由已保存的结构化视图编译；尚未实现原版全部富正文、原版完整高级图表配置/业务分析图、WASI/Python 报告沙箱和 report_resume/重新确认协议。
- 单份冻结 JSON 最多 32 MB，HTML 最多 8 MB，PDF 最多 50 MB/200 页；同时最多生成 2 份报告，一次最长 120 秒，其中后台 PDF 校验最长 30 秒、V8 老生代上限 384 MB。超限或无法完整排版时明确失败，不交付部分结果。
- 目前失败重试和“重新生成”用于恢复同一份冻结版式；更换语言、格式或标题应新建报告。通用文件/成果中心仍待继续补齐。
