## 本轮已落地

| 部分 | 当前实现 | 使用与验证范围 |
|---|---|---|
| 统一任务 | 分析任务与普通聊天持久一对一关联；共享标题、固定状态、工作目录；统一列表、搜索和既有聊天续接 | 原分析记录保留；失效聊天明确提示，不自动改绑 |
| 工作台对话 | 同一任务中的对话、数据、分析、依据、文件、报告导航；真实 ChatPage、消息与工具运行时接入 | 编辑／重试／删除／续问已接通；工作台分支独立关联任务、重映射引用并保留历史依据；原版完整诊断及变体迁移仍需专项对照 |
| 分析工具 | 14 个内置工具进入既有 Agent 发现和调度，访问当前任务数据与允许的连接 | 执行当前受控计算／只读 SQL／DAX／显式关联，不能通过参数选择其他任务或替换账号 |
| 文件代码执行 | 在原有 exec 增加声明输入与完整表格交付，真实进程退出后登记 PBI_RESULT_PATH，接入当前计算、依据、发布与 /7 报告 | 附着式最长 120 秒、完整结果校验/原子登记/重放/取消/中断恢复已验证；长期后台与完整原版协议仍缺 |
| 正式结果 | 实际运行 → 依据 → 候选 → 同会话／模型完整读取与随机凭据 → 核对来源版本 → 发布 → 冻结 PDF／JSON | 不接受模型自行填入结果数字；普通聊天文本不等于已发布正式回答 |
| 执行与恢复 | 持久调用状态、参数摘要与结果；成功重放；取消／退出清理；重启标记中断 | 未知结果先读保存状态，不盲目重复计算或发布；报告取消／失败不返回成功成果 |
| 桌面使用 | 沿用浅深色和原工作台样式；修复长 Windows 目录挤出对话输入区 | 开发 E2E 隐藏并禁止聚焦，不抢用户屏幕；测试截图和日志外置 |
| 续写与消息操作 | 空闲回答后生成可编辑建议、Tab／Esc、模型与推理设置及回退；消息编辑保留引用，失效引用阻止重试；独立分支、传递计时与设置跨窗口同步 | 受控建议不自动发送或执行工具；分支远程连接需要重新绑定；细粒度 provider 计时和旧变体迁移未宣布完成 |
| 任务引导与交互 | 五类上手主题与离线示例、结构化来源／表／字段／真实度量引用、三类原文追问、按任务恢复面板和引用草稿 | 主进程校验来源与版本；旧文字保留原文；界面状态恢复不自动执行分析 |

具体操作、14 个工具及参数边界见 [统一任务使用说明](task-workspace.md)，设计与数据边界见 [任务工作台设计](task-workspace-design.md)，实际检查结果见 [本轮验证](verification-task-workspace-2026-11-14.md)。合成模型协议验收只证明工程链路，不替代真实模型和业务数据验收。

## 待真实环境验收与暂缓项

- 真实模型理解效果、实际业务数据库／TLS、真实 Desktop／PBIX、本地模型发现与取数、云端租户／权限／容量／XMLA，以及干净机器安装仍需独立验收。
- 用户后续补充 Entra 公共客户端应用 Client ID、Tenant ID、国际云／中国云配置后，再安排真实云连接验收；不收集密码或访问令牌。
- 可选 Fabric 模型定义读取仍暂缓。微软要求的 `SemanticModel.ReadWrite.All` 包含更宽权限，按用户要求先记录，不自动申请。
- 本机缺可用 Windows SDK，当前开发 SQLite 原生模块使用受校验的预编译引导；干净机源码重编译与正式安装发行仍未完成。
