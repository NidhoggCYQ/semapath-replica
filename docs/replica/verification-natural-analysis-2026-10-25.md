## 自然语言端到端内容

通过本地合成 OpenAI 兼容 HTTP 服务，运行真实模型配置 → ProviderRuntime → 严格计划 → Worker 完整数据计算 → HTTP 模型复核 → Vue 回答/图表 → SQLite 保存。正常开发版没有预置该合成模型，也不会自动连接测试服务。

1. 未配置模型时显示配置入口，不能点击分析；配置并启用聊天模型后可以刷新和选择。
2. 直接提问“按区域汇总销售额，找出最高区域并计算占比”，真实结果华东 0.3、华南 8；排名首项为华南；华东占比 3.614457831325%。模型请求中未包含本机文件完整路径。
3. 点击华东 0.3，依据定位 C2=0.1、C3=0.2。点击占比，显示 0.3 / (0.3 + 8) × 100 及精确表达式，再点击输入继续回到原始单元格。点击排名图形可追到华南计算输入。
4. 整次发布后正常退出并重启，问题、图表依据、正式回答状态保持。继续追问“只看华东呢？”，新请求带前一问题上下文，计算使用真实筛选后的完整数据。
5. 新回答后修改源文件，旧草稿发布被拦截；原正式回答和指纹保持。更新绑定文件版本后再次提问，华东为 1.3。
6. 执行两查询期间比较：2026-10-03 起与之前对比，当前 8、基期 1.3、差额 6.7、增幅 515.384615384615%。差额可追到两个输入结果，基期再追到 C2/C3。整次发布后两份关联运行均为正式状态。
7. 缺少利润字段时要求补充口径，不保存数字结果。错误字段计划校验失败，历史记录数不增加且问题保留。
8. 停止等待中的请求会实际中止 HTTP 连接，不新增半份问题或计算；随后可再次成功分析。
9. 1280×800 深色窗口无横向溢出；长回答在浅色与深色窗口中均可看见追问输入。桌面测试未产生 renderer page errors。
