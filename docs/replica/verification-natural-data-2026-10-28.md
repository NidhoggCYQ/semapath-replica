## 可追溯与恢复

模型 HTTP 边界使用明确的本地合成响应，经真实 ProviderRuntime／类型化 IPC／SQLite／SheetJS Worker／Vue／Chromium PDF 执行。MySQL 返回长整数和十进制文本，经客户区域 Excel 关联后精确汇总为华东 0.3、华南 5、未匹配 2.5。Power BI 合成原生协议返回两条小数，按客户精确汇总为 0.3。

实际查询、结果行数及来源指纹显示在取数过程；结果可以打开为数据快照。关联后的数字可追至 SQL 返回 `数据!D2/D3` 和区域文件单元格，Power BI 可追到 DAX 返回 `数据!C2/C3`。来源保留取数问题、模型身份、结构摘要、查询全文与摘要；报告冻结完整返回值和关联根来源。长整数、前导零标识和原始十进制文本在冻结依据中保留。

模型失败、保存失败、取消不提交半成品，清理本次快照并保留原有文件。零行结果保存真实空快照和澄清；重复取数达到上限时回滚；固定下钻不能扩大到在线数据。SQL AST 拒绝跨库、嵌套跨库、未知表、自动 CTE 和纯常量；DAX 拒绝未知引用表、常量伪造结果和元数据／外部访问。已有文件模式保持原合同。

整次发布后移除测试源文件，仍可生成 PDF／完整依据 JSON；摘要与保存记录相符。重启恢复取数记录和正式状态，桌面测试没有 Renderer page error。合成模型协议不能证明真实模型会正确理解所有业务口径，真实业务语义单独验收。
