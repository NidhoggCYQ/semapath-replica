## 新增的持久回归

44 项分布为 SQL 语句边界 25 项、关联/报告 9 项、真实 MySQL 协议 7 项、加密连接存储合同 3 项。

- 允许单条汇总、子查询、简单 CTE、窗口函数和字符串中的普通字符；拒绝写语句、多语句、注释、会话变量、文件访问、锁、延时函数、未知/限定函数和 Unicode 函数绕过。
- 真实 MySQL 对 DECIMAL/BIGINT 返回字符串；检验 `9007199254740993123` 和 `12345678901234567890.12345678901234567890` 完整保留，SQL 的小数求和为 `0.30000000000000000000`。
- 使用具有 UPDATE 权限的专用合成账号绕过客户端检查，服务端仍以 `ER_CANT_EXECUTE_IN_READ_ONLY_TRANSACTION` 拒绝更新。生产连接无需管理员账号。
- 检查零行、重复列名、超过 5000 行和超过列数上限；不以截断结果冒充完整查询。鉴权错误返回稳定代码，不暴露密码或服务端原始错误文本。
- 实际执行长查询，验证取消后继续读取；另一项不依赖界面取消的查询在约 20 秒触发服务端执行时限并返回 SQL_TIMEOUT。
- 多对一/一对一唯一性、空键不匹配、左/内关联、前导零文本与数值键、结果上限、源变化、连续关联展平与 SQL 根来源冻结。
- Excel 1904 日期系统关联后仍可按日期筛选/月分组，依据保留原始日期序列值；SQL 40 个业务字段加定位列可进入目录，不扩大普通 Excel 的目录限制。

## 实际桌面流程

新增 07 通过真实 IPC、MySQL2、Worker、SQLite/任务保存与 Vue 界面执行：

1. 配置合成 MySQL 连接，测试、保存、读取表结构、预览真实订单；界面不回显已保存密码，连接文件不含合成密码、主机、用户名和数据库的明文。
2. 写操作被拦截且没有登记新数据；长查询可取消；执行 SELECT 后登记 SQL订单 快照，精度与大整数保留，刷新不可改写快照会被拒绝。
3. 导入合成客户区域 Excel，以文本客户键左关联，多对一检查通过；4 条左记录中 3 条匹配、1 条未匹配。
4. 经实际 ProviderRuntime 和本地合成 HTTP 模型规划/复核，对关联快照按区域汇总，结果为华东 0.3、华南 5、未匹配组 2.5。数值依据同时定位 SQL `数据!D2/D3` 和 Excel `客户区域!B2`；SQL 原始小数和全部返回记录仍在冻结来源中。
5. 发布后移除测试原始文件及生成快照文件，再生成 A4/16:9 PDF 和依据 JSON；不重新取数或调用模型。PDF 包含 SQL、源指纹、关联键/关系/方式及原始单元格示例，JSON 保留完整 SQL 返回值和关联行映射。
6. 重启同一独立测试配置，连接可解密并再次测试，已发布分析和两份成果仍在；没有 renderer page error。

模型两次响应是明确标记的合成协议夹具，用于证明取数、计划、执行、复核、依据及报告链路；不是实际业务模型理解或经营结论质量证明。当前代理只分析已登记快照，不自动选择连接、运行 SQL 或决定关联键。

## 界面和 PDF

界面继承已有蓝色、系统字体、原生表单和浅深色主题。修正了 TLS 复选框受父级纵向 label 样式影响的问题。唯一一次源码 detector 对六个改变目标返回空数组；键盘焦点按真实 DPR 验证，源码 2px 在 125% 缩放下计算为 1.6px，符合物理像素量化。

独立审阅首轮指出，长页面中的查询反馈离查询动作太远。现已把查询错误、进度、取消及保存阶段提示放到查询输入/执行附近，并在反馈出现时滚动至可见位置；连接测试反馈继续在连接表单附近。端到端新增错误与取消按钮完整进入视口的断言，覆盖加载表结构和预览后的长页面，并在实际取数阶段截图和取消。独立复核将该 P1 评为 resolved，disposition: ship；此结论仅覆盖该项修复，不扩大为全产品批准。精确记录在缓存 `data-qa-2026-10-28/review-verdict.json`。文档核对确认是既有系统普通扩展，保留现有 DESIGN.md 和缺省 sidecar 状态。

PDF 通过应用内容检查及 pdf-parse 验证文本，用 pypdf/pdfplumber 独立核对尺寸与页内文字，Poppler 以 105 dpi 渲染所有十页并检查排版。A4 约 594.96×841.92 pt，演示版 960×540 pt；字符越界 0、外部 URI 链接 0。冻结依据摘要与保存文件 SHA-256 一致，SQL 密码不进入任务、模型提示或报告。
