# 续写建议与消息操作

本轮对照 SemaPath 0.2.19 的 F005、F006、F013，开发工程仍为 `E:\USERS\Desktop\SemaPath复刻开发\app`。建议和普通聊天不替代正式分析发布；数字、图表、依据及报告仍使用现有原生分析链路。

## 使用方式

1. 在“任务对话”完成一次提问。最后一条助手回答正常结束、没有草稿或排队输入时，输入框下方会出现一条下一问建议。按 **Tab** 或点击建议填入草稿，编辑后自行发送；按 **Esc** 忽略。开始输入、插入引用、准备附件、使用输入法候选或切换任务时，不会把旧请求结果填进草稿。停止、报错和未完成回答不产生建议。
2. 在“模型与应用设置”的常规页面找到“续写建议”。可以关闭建议，跟随当前会话模型，或指定已启用的聊天模型及推理设置。指定的不同模型不可用、超时或输出无效时，尝试当前会话模型。设置页面显示失败和回退结果；没有配置模型时不产生建议。模型能力不支持的推理选项应改为“自动”。
3. 移到用户消息上，选择“编辑消息”。文字和数据引用一起进入编辑器，引用可以选中删除。点击“保存”或按 **Ctrl+Enter**（macOS 为 Cmd+Enter）保存并重新生成；Esc 或“取消”退出编辑。原生层校验失败时保留本次编辑；成功保存后，原问题之后的旧对话会被替换，不能继续把旧回答当作新问题的回答。附件、技能和必要元数据保留。
4. 选择“重新生成”时，重新核对原消息引用的任务、来源和版本。数据引用已失效时提示原因，保留旧回答；恢复来源或重新选择引用后再操作。正在生成或等待工具交互时，应先结束当前操作。工具或上下文预算停止后，“继续”发送新追问，不把历史执行记录改写为新执行。
5. 在助手消息上选择“分叉到新会话”。工作台直接进入新的独立任务，保留所选消息及以前的已发送内容、当时已存在的计算和数据依据。消息及引用 ID 在分支内重新映射；分支中的追问、改名、计算和报告不会写回父任务。来源快照和历史结果仍可追溯、生成报告；远程表／度量连接需在此分支重新绑定，已有保存快照仍可读取。分支提示会说明这一边界。
6. “删除消息”先确认，确认后删除该条及后续对话；取消保持原状。已保存的分析结果及冻结报告不会随消息操作改写。复制用户消息会包含可见引用标签；助手仍支持复制 Markdown、短按复制当前消息组图片、长按 800ms 从顶部截图，键盘 Enter/Space 与 Shift+Enter/Space 对应两类截图。
7. 在常规设置开启调试信息后，助手工具栏可打开“消息传递轨迹”、请求参数和 Tape 检查。消息传递轨迹记录实际收到的提交、原生首次更新、客户端收到更新、首次呈现和结束／失败时间，并显示已保存的模型请求时点。未采集的阶段不推算延迟，旧消息和分支继承消息不补造新执行计时。刷新可读取后续记录。

## 数据与恢复边界

- 续写建议最多读取八条公开消息，每条最多 1600 字符；不读取推理、附件正文、密钥或全部原始数据。模型不提供工具，禁用搜索，独立限时 20 秒。每条近期回答共享一次请求，设置或模型变化会使旧建议失效。建议只保存到用户选择接受的草稿中。
- 消息编辑和重试在原生层重新验证引用。分支在同一事务内复制消息、创建独立任务并重新登记上下文；失败回滚。父任务工具回执不复制为分支的新回执，分支需要新的读取与复核后才能发布新的正式结果。
- 分支只复制边界之前的历史分析和必要祖先，不复制后续分析。父任务冻结报告不自动成为新成果；分支可从自己的历史结果重新生成、保存与校验报告。
- 设置、会话、引用、任务关联和实际采集的传递计时可在重启后恢复。界面恢复不自动执行分析，已忽略的建议也不触发发送。

## 仍需单列的原版验收

本轮完成日常消息操作在统一工作台与结构引用上的接通，不表示全产品一比一完成。原版 provider attempt 的首次底层事件／取消请求计时、完整 Tape 传递事件导出、旧版多答案变体的完整迁移和窗口级恢复仍需专项对照。现有版本按钮沿用底座，不把重新生成产生的新 ID 冒充成已有多版本数据。

真实模型的建议质量、真实业务数据和复杂附件需另行验收。Entra Client ID、Tenant ID、云环境配置仍待后续补充；可选 Fabric 宽权限仍不申请。开发验证保持后台隐藏，不操作原版程序和用户模型。
