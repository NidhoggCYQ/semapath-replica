# 任务引导、数据引用、文字追问和面板恢复

本轮继续对照 SemaPath 0.2.19 的任务交互。开发工程位于 `E:\USERS\Desktop\SemaPath复刻开发\app`。本功能在现有任务、分析工具、数据依据和报告链路上增加交互，不改变历史计算和已冻结报告。

## 使用方式

1. 打开左侧“数据分析”，点击任务列表下方“任务引导”。首次没有任务时也会显示引导。五个主题分别介绍模型、任务、数据、文件和后续操作；主题与示例依据的展开状态会保存。离线示例使用明确标注的 80／100／20 演示值，不调用模型，也不登记为用户成果。
   有任务时，引导会只读检查已登记文件和已绑定连接的结构，分别显示数据与文件的可用状态。只有可用数据库连接、没有文件快照时，数据可以就绪，文件仍为待完成；连接失败显示不可用并提供“重新检查数据”。
2. 创建或选择任务，登记 Excel／CSV，或使用已有 MySQL／Power BI 连接。在“任务对话”输入 `@`，再输入表名或字段名。候选包括来源、表、字段及真实 Power BI 度量；工作目录文件搜索仍保留。候选较多时输入更多名称缩小范围，加载失败可重试。
3. 选择候选后，输入框会插入引用标签。继续输入问题并发送。引用保留当前任务、来源、工作表／表名、列或度量和结构版本；主进程会重新核对，拒绝跨任务、失效文件或变化的结构。模型通过 `analysis_get({contextId})` 读取来源，标签本身不作为计算结果。
4. 选中当前任务的助手回答或可核对的分析结果文字，在浮动工具条选择“为什么”“拆开看”或“纠正口径”。系统将原文引用和相应问题追加到当前任务对话草稿，保留已有草稿，不会自动发送。选区限 2000 字；无法在已保存内容中核对的选择会提示重新选择。
5. 点击已发送消息中的引用标签，可查看来源、时间、版本和原文，并定位来源或原回答。历史文字引用保留当时的文字；原回答变化或移除时显示相应状态。数据版本失效时需要重新选择引用，不能借助旧标签继续取数。
6. 在任务间切换或重新启动开发版，工作台恢复各任务的页签、来源／工作表／表头、结果与依据选择、自然分析历史、报告选择、展开状态、滚动位置、手动计算参数及聊天侧面板尺寸。聊天草稿沿用原有草稿保存机制，包含结构化引用。

## 接口与恢复边界

引用与原文保存在 `replica_analysis_contexts`；界面状态保存在 `replica_analysis_ui`。已有用户数据库会通过表目录创建新表，不重写旧分析。引用 ID 必须属于当前任务，客户端提交的标签会被主进程保存的标签替换。正在处理的结构读取具有超时、取消和关闭围栏，避免退出后写数据库。

新增 IPC 接口包括 `analysis.references.catalog/create`、`analysis.quotes.create`、`analysis.context.get`、`analysis.panels.get/save`、`analysis.guide.get/save` 和只读 `analysis.workspace.lookup`。已有 `analysis_get` 支持 `contextId`，与 `runId`／`turnId` 互斥；已有分析、依据、正式发布和报告导出协议继续使用实际运行记录。

恢复界面状态不会自动执行分析、发布回答、导出报告或申请连接权限。本地预览按当前页重新读取；失效的来源和结果选择回退到当前任务有效项，损坏状态回退到默认值。聊天侧面板只恢复工作区／浏览器页签、开关、尺寸和导航宽度，不恢复临时 MCP 所有权、调试器会话或自动打开外部浏览器。

已保存的有效方法参数可随计算面板恢复；未通过方法校验的临时输入、引用详情的临时打开项、图表预览切换、窗口级布局及所有消息动作的原版逐项验收不在本轮完成范围。结构引用也不会把未连接的数据源自动配置成可用连接。

## 尚未替代的验收

当前功能不表示整个原版已完成一比一复刻。续写建议与常用消息动作的后续实现及边界见 [消息操作说明](message-actions.md)；细粒度诊断、旧变体迁移、窗口级恢复、开放文件执行协议、完整工具参数、指标口径库等继续按工作包推进。真实模型理解、真实业务 MySQL／Power BI、本地 PBIX、云租户权限与干净机器安装仍需独立验收。

Entra 公共客户端应用 Client ID、Tenant ID 和云环境配置仍待用户后续提供。可选 Fabric 模型定义读取仍暂缓，不自动申请 `SemanticModel.ReadWrite.All`，不收集密码或访问令牌。

设计与边界见 [设计说明](task-interactions-design.md)，实际后台检查结果见 [验证记录](verification-task-interactions-2026-11-14.md)。
