# 续写建议与消息操作

本轮目标对应原版 F005、F006、F013。保留原版工具栏、上下文菜单和桌面工作台样式。

## 续写建议

最近一条已完成的助手回答、会话空闲、没有草稿或等待处理的交互时，延迟 400ms 请求建议。主进程限定会话、消息归属和最新回答，最多读取八条公开对话，每条最多 1600 字符，不读取推理、附件正文或密钥。调用已启用的聊天模型，不提供工具，禁用搜索。独立预算、20 秒超时、每会话去重和最近 100 个结果缓存。请求结束重新核对上下文，过期结果丢弃。

设置可跟随会话模型或指定模型及推理选项；指定模型失败时回退会话模型。错误只显示在设置状态，不打断正式回答。Tab 填入、Esc 忽略；建议永不自动发送，不成为正式分析结果。草稿、输入法、@ 菜单、排队、生成和只读状态优先。

## 消息与分析依据

编辑使用支持结构化引用的编辑器；文本和引用一同提交，并在原生层重新校验。重试必须在删除旧回答之前校验引用。删除保留原版“从此处删除后续消息”的确认语义。失败提供可恢复提示。

分支复制所选消息及以前的已发送记录，重新分配消息和上下文 ID，并单独关联分析任务。分析历史按分支边界复制不可变快照；引用中的消息来源映射至新消息。分支操作与任务关联在同一事务内完成，失败回滚。父任务、父消息和工具回执不修改；历史工具调用不冒充新执行。工作台切换到新分支。

## 界面变化

```text
BEFORE  [空输入框                     ]   [消息工具栏…]
AFTER   [可编辑的续写建议              ]   [消息工具栏…]
        [Tab 填入 / Esc 忽略           ]   [编辑保留引用 / 分支进入新任务]
```

使用现有系统字体、蓝色焦点、分隔线及图标。窄面板允许工具栏换行；说明保持可读，按钮有键盘名称。后台 Electron 隐藏且不可聚焦，截图、日志和审计材料外置至缓存目录。
