# 统一任务工作台与分析工具

目标基线：SemaPath 0.2.19。当前落实 R01／R02 的任务关联和受控分析工具链，完整原版的剩余功能仍按范围账本推进。

任务引导、`@` 表／字段／度量引用、文字选区追问和按任务恢复面板的新增操作见 [任务交互说明](task-interactions.md)。

## 使用流程

1. 在左侧打开分析工作台，创建任务或选择已有任务。列表同时呈现已有分析任务和普通聊天；搜索可以匹配标题、工作目录，任务可固定到列表前面。
2. 在任务中添加 Excel／CSV，或按既有数据连接流程显式绑定 MySQL／Power BI。本轮分析工具只能访问当前任务登记的来源和允许的连接，不负责登录或申请额外权限；通用文件与终端工具沿用既有聊天权限模式。
3. 按需要选择工作目录；关联后与该聊天共用标题、固定状态和工作目录。工作目录是聊天与文件工具的工作位置，设置目录本身不会把其中所有文件登记为分析来源。
4. 切换到“对话”，使用已配置的默认模型开启该任务的聊天。未配置模型时会提示进入设置；已有聊天保持其模型和历史。沿用既有消息编辑、分支、输入草稿和导出能力。已有聊天也可从应用侧栏的分析入口进入对应工作台。
5. 直接提问，例如：“按区域汇总本任务 Excel 的销售额，核对原始依据，确认正式回答并导出 A4 报告。”支持工具调用的模型可按真实结构取数、计算和读取依据。模型是否正确理解业务仍需使用真实模型与业务数据验收。
6. 在分析页查看保存的候选／正式回答、图表与精确值；点击数字进入原始单元格和派生依据。“分析工具记录”显示已保存的调用状态，报告页管理 PDF 和冻结依据 JSON。

原有分析页的自然语言分析、手动计算、方法、框架和下钻继续可用。对话采用通用聊天运行时，因此普通聊天文本不自动等同于已核对的正式分析回答；正式状态以分析页中的保存记录为准。

## 工具契约

协议版本为 `replica-analysis-tools/1`，工具服务名为 `semapath-analysis`。这些是主进程内置工具，通过既有 Tool Surface 发现和 DeepChat Agent 调度，不需要另行安装 MCP 服务；外部 ACP Agent 的直接调用联动尚未作为本轮完成项。参数契约位于 `src/shared/analysisTools.ts`。

| 工具 | 当前实际能力 |
|---|---|
| `datasource_context` | 当前任务的已登记来源、绑定连接、运行与回答摘要 |
| `datasource_schema` | 文件结构／样本，或绑定连接的受限真实结构；样本不作为计算依据 |
| `datasource_query` | 文件受控计算、只读 SQL／DAX 快照或显式跨表关联 |
| `analysis_evidence` | 保存的实际值、精确值、公式、原始单元格和来源；计算值与输入单元格分别分页 |
| `analysis_get` | 任务状态、运行，或完整候选及全部计算输出；形成模型读取候选的记录 |
| `analysis_frame` | 记录任务问题／假设框架草稿；提交回答时需显式引用对应框架 |
| `analysis_progress` | 保存简明任务进度，不能替代计算或发布结果 |
| `tool_schema` | 读取当前工具契约与九种方法规则 |
| `arguments_repair` | 校验替代参数并返回错误字段；不直接执行计算 |
| `chart_schema` | 读取十四种受支持图型、方法绑定与适用约束 |
| `answer_submit` | 从已保存运行及兼容视图构造候选，不接受模型自行填写结果数字 |
| `answer_confirm` | 同一会话与当前模型读过该候选，携带读取响应中的 `reviewReceipt.id` 作为 `reviewReceiptId`，重新核对摘要与来源版本，再正式发布 |
| `answer_resume` | 读取保存的候选与计算，恢复核对过程，不重新执行取数 |
| `report_export` | 从已发布回答生成 A4／16:9 PDF 和冻结依据，等待生成完成或取消 |

标准顺序为：上下文 → 真实结构 → 实际取数／计算 → 数据依据 → 提交候选 → 再次读取完整候选 → 确认发布 → 导出报告。确认步骤保护实际结果与来源一致性，并不保证模型已经完成业务判断。

## 持久化与恢复

分析任务和聊天分别保留原有主键，通过 SQLite 一对一关联。旧分析任务首次开启对话时建立关联；已有普通聊天进入分析或首次使用工具时登记一次分析记录。不会复制、合并或删除历史分析。

工具以会话、消息、调用标识及规范参数摘要登记执行。成功调用重放保存的结果；同一调用标识换参数会拒绝。重启时未完成的记录标为中断，先核对已保存状态，不盲目重跑。停止请求和应用退出会取消未完成作业并释放计算／连接资源。已经原子保存的结果仍保留。

删除关联聊天后，历史分析保持可读，对话提示会话失效；当前不自动创建替代聊天或改绑其他会话。工具不能通过参数选择其他任务。文件名、单元格和连接返回值均为待分析数据，不能作为执行指令。

工具上下文不包含原生来源路径或完整原始快照载荷。完整计算输出保留在候选中，原始输入通过 `analysis_evidence` 独立分页读取；完整依据仍保存在本地和冻结成果中。单次工具响应上限 8 MB，超限不会得到候选已读凭据。所选模型必须支持工具调用，并具有足够的上下文；按实际模型能力配置，不应虚报容量。

## 本阶段边界

已接入受控计算、只读连接、依据、候选发布和报告能力，并补充 [文件代码执行与完整结果登记](file-execution.md)：附着式 `exec` 可捕获声明输入版本、接收 `PBI_RESULT_PATH` 完整表并接上已有分析。后台表格执行、全部富正文／历史修订协议、自由业务图、多种关系／partition、业务指标口径库、按需方法知识与自定义报告沙箱仍未完成。

真实 PBIX、本地 Power BI 模型、微软云端账号／租户／容量／XMLA 和真实模型业务效果继续单独验收。Entra Client ID、Tenant ID、国际云／中国云配置待用户后续提供；可选 Fabric `SemanticModel.ReadWrite.All` 仍暂不申请。无需提供密码或访问令牌。
