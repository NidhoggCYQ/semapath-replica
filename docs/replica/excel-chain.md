# Excel 任务链路

## 使用路径

启动开发版 → 分析任务 → 新建任务 → 连接数据 → Excel → 添加文件（可多选）。

文件登记在当前任务下，切换到“任务文件”可查看工作表、表头和每页 50 行的只读预览。可以手动调整表头所在行，重复字段通过原始列字母区分。添加文件不会自动发送给模型。移除引用只更新任务绑定，不删除原文件或历史计算。

在“分析工作”默认进入“直接提问分析 Excel”。选择已配置的聊天模型，输入问题后由模型制定结构化计划，完整数据在本地计算，再由同一所选模型复核。支持追问、进度与停止。模型配置和支持范围见 [自然语言分析](natural-analysis.md)。切换“手动计算”可自行选择字段与筛选并运行求和、平均值、记录数、最小值和最大值；此手动入口的问题仅用于记录任务说明。

回答里的数字、条形图、折线图和数据表引用同一份计算记录。点击回答数字或图形可跳转到“数据依据”，查看精确值、口径、期间、单位、文件位置与指纹、原始行和单元格、执行计划及结果记录。

核对后点击“确认并发布”。服务端校验候选回答 hash、绑定版本和当前源文件 SHA-256 后，原子保存正式回答。任务与历史结果保存在应用已有 SQLite 数据库，跟随原有数据库的配置与生命周期。

## 数据规则

- 真实支持 `.xlsx`、`.xls`、UTF-8 CSV；公式使用工作簿已保存的缓存值，不执行重算，也不运行 VBA 或外部链接。
- 采用 SheetJS 0.20.3。`cellFormula`、`cellNF` 和 `sheetStubs` 保留公式、数值格式与缺失缓存，`nodim` 避免只按不完整的声明范围读取，`WTF` 使解析错误明确失败。参考官方 [读取选项](https://docs.sheetjs.com/docs/api/parse-options/)。
- 十进制系数采用 BigInt，求和/极值保留十进制值；平均值保留精确分子和分母，展示最多 12 位小数并记录舍入提示。无法恢复 Excel 本身已经丢失的原始数值精度。
- 数字文本仅接受明确的十进制或科学计数格式。错误值、日期格式数值及布尔值不会被静默加入数值度量。
- 空数值不等于 0；空分组保留为空白类别。完全空白的行不参与记录数。数值筛选中的空值不匹配；手动等值与包含筛选默认使用原始值文本；自然语言计划可显式指定文本、数值或日期语义，支持同列集合匹配。
- 隐藏行也纳入计算；不自动补齐合并单元格。手动入口的期间与单位是用户提供的结果说明，不自动生成日期筛选。自然语言入口会将日期要求转换为实际筛选条件，可按日/月分组；均不自动换算单位。
- 预览不是正式依据。计算只使用与记录指纹一致的输入字节；更新文件版本不会改写历史结果。发布后结果保留当时来源版本，不表示源文件此后没有变化。
- 执行记录为实际运行的结构化计划与固定引擎版本，不冒充任意代码执行日志或模型推理。

## 资源边界

每个文件最多 20 MB，每张表最多 50,001 行（包含表头）、256 列，工作簿展开的总矩形范围最多 500,000 单元格，单次结果最多 100 个分组。超过上限会停止，不截断后发布部分结果。

读取与计算运行在独立 Worker，最多并发 2 个，队列最多 12 个，单个作业时限 30 秒，V8 老生代内存上限 256 MB。文件解析失败、资源不足或超时会明确返回错误，任务不保存半份计算结果。

## 当前复刻边界

本轮是第一条真实 Excel 业务链路。任务/数据/依据/结果的组织方式沿用原版；页面和功能尚未达到 SemaPath 0.2.19 的完整复刻验收。

自然语言计划、模型复核及整次候选回答发布已实现；执行范围限定为经过校验的 Excel 结构化查询。原版任意代码分析及文件结果协议、完整业务分析图及高级图表配置、原版完整报告模板与协议、Power BI 本地与云端、SQL 连接尚未接入。其他连接入口显示开发状态；当前实现不代表原版完整 Agent 协议已经对齐。
