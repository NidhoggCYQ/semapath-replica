## 方法与数值验证

- 周期：实际日历间距、缺期断线、相邻差额和变化率；未关闭期间保留 unknown，不补零。
- 结构：0.1+0.2 精确为 0.3；指标份额和记录份额分开；带负值保留正负贡献，拒绝饼环误用；联合百分比按各分类自己的分母计算。
- 分层：业务阈值等号归入高侧；Type 7 分位数、Sturges 分箱、1.5 IQR 实际须端与离群值；空组保留，不把无观测均值写为 0。
- 矩阵：配对缺失、明确对象唯一性、阈值与四象限覆盖、气泡零规模均有明确处理。
- 指标分解：加法精确恒等、所有因素与残差；除法零分母不伪造计算值，关系不符显示 fail。
- 漏斗：同一对象 0/1 标记的逐行嵌套、相邻与总体转化分别计算；阶段反增拒绝有效漏斗；时长流程不输出人数转化。
- 相关：Pearson、并列平均秩 Spearman、常量未定义；超过 JS 安全整数的原始观测仍通过精确充分统计得到系数；开方系数标注近似并保留公式。
- 标签/MECE：重叠、未匹配、空组和多重归属保留，MECE 不重复累加；空白与同名占位文本不合并，无法唯一绑定的联合图明确不可用。
- 图形安全：全部十四类型均由真实计算值生成；外来 HTML 转义、绑定 ID 必须存在，原生路径不进入冻结 source。
- 深色对比度：对正/负色、两种主题、五档透明度共 20 种组合核对文字至少 4.5:1；中位线在实际深色箱线图可辨。

新增提示内容曾使既有连续追问触及上下文上限，已改用复用 schema 引用和复核时按执行方法加载规则，并增加四轮追问后的 32K 上下文预算回归。原有上下文保护未放宽。增量构建遗漏预加载共享契约的问题已修复为 main/preload 同步构建；手动方法入口在真实窗口执行并点击图形进入单元格依据。
