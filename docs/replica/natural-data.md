# 自然语言读取连接数据

在已有任务连接上直接提问，由所选聊天模型读取真实结构、生成只读 SQL／DAX，取得完整结果快照，再进入原有本地计算、模型复核、图表、数据依据、正式发布和报告。可选择现有文件一起分析，由模型生成显式关联计划；业务键、期间或口径不明确时应澄清。

```text
BEFORE  手写 SQL／DAX → 保存快照 → 手动关联 → 提问分析
AFTER   选择允许的连接与文件 → 提问 → 结构 → 只读取数／显式关联
                                        → 完整快照 → 计算／复核 → 依据／发布／报告
```

## 使用

1. 在上方“连接数据／管理连接”保存自己的 MySQL 连接，或绑定 Power BI 模型。云端仍需自己的 Entra 应用配置和 Microsoft 登录，不附带账号或凭据。
2. 返回“分析工作 → 直接提问分析数据”，选择聊天模型，在“分析数据范围”选择“自动读取连接数据”，刷新并勾选允许读取的连接。任务可以没有文件。
3. 如需关联，展开“可一起分析的现有文件”，勾选来源。明确业务键、期间和口径，例如“读取订单库本月订单，以客户编码关联客户区域文件，按区域汇总订单金额并保留未匹配客户”。字段须以自己的数据为准。
4. Power BI 云端可选 REST／XMLA 查询通道。自动 DAX 需要可读取的模型结构，通常需 XMLA 访问权限；只有已知 DAX、没有结构权限时，可用连接面板的手动 DAX 入口。本地固定显示并使用“ADOMD（本地）”，不提供会被忽略的通道选项。
5. 执行中可停止，问题保留。回答上方展开“查看取数过程”，核对实际查询、结果行数和摘要，并打开快照。数字和图表继续追到原始返回记录及关联文件单元格。
6. 核对后发布，导出 A4／16:9 PDF 和冻结依据 JSON。`analysis-report/6` 包含取数问题、模型、结构摘要、实际查询及摘要、完整结果、关联根来源。导出不重新取数或请求模型。

“仅分析现有文件”保留原流程。固定查询／输入行下钻不能自动取数扩大范围，需要时使用“新建问题”。历史快照不随在线数据刷新而变化。

## 边界

- 每次最多 3 个 MySQL 连接、1 个已绑定 Power BI 模型、6 个附带文件；最多 3 次成功查询、1 次关联、6 次取数决策和 10 次模型调用，含 JSON 修复、分析与复核；总时限 5 分钟。文件模式仍为 4 次调用、180 秒。
- 完整结构目录上限 55,000 UTF-8 字节；超限失败，不截掉表冒充完整结构。实际模型上下文及 80,000 字符提示词限制同时校验。
- 自动 SQL 在原有语句检查、只读事务之外，使用 AST 限定已列出的当前库表及派生查询，保守拒绝 CTE；手动入口保留既有 CTE 子集。SQL 单次最多 5,000 行、40 个业务字段、4 MB，服务端查询上限 20 秒。DAX 沿用原有结果和时限限制，固定所选模型并拒绝结构外已引用表、常量伪造结果及外部／元数据访问。
- 整数／十进制保留返回文本，浮点保留源系统近似语义。DAX 结果可能已聚合，不代表底层明细。零行结果是空范围，不能当成销售额零。超限不保存截断结果，查询错误最多修复一次。
- 关联复用 left／inner、多对一／一对一、文本／数值键合同，每侧最多 2,000 行、总计 40 列、8 个根来源；右键必须唯一。文本键保留前导零。匹配成功本身不证明业务关系正确。

活动请求固定连接配置、模型绑定和账号，配置修改被阻止，账号退出或结构变化使旧会话失效。来源、取数记录、运行和回答一次保存；失败／取消清理本次创建的文件，已有数据保留。取数后有效澄清会保留完整快照供后续使用。最终保存阶段不再接受停止；云端取消仅表示本地停止等待。

模型接收选中库／模型名称和真实结构、文件结构与有限样本、实际查询、结果相关信息和计算结果；连接密码、访问令牌、主机／用户名配置和本地路径不进入提示。真实模型业务理解能力仍需单独验收。

共享合同在 `analysisAcquisition.ts`，主流程在 `src/main/analysis/retrieval`。连接会话返回载荷，不递归获取任务锁；由 `AnalysisService` 统一保存／回滚。`retrieval.test.ts` 覆盖实际工作簿、精确计算、关联、指纹和回滚；桌面测试 `09-natural-data.smoke.spec.ts` 使用真实 ProviderRuntime／IPC／Worker／UI。MySQL 使用缓存中的隔离真实实例，模型和 Power BI 原生业务协议使用明确的合成响应，仅在测试进程启用。

真实 PBIX／微软账号与模型语义效果未用合成验收替代。完整开放式 Agent、自由业务图、任意代码、模型写回及全套报告模板仍待开发。设计见 [natural-data-design.md](natural-data-design.md)。
