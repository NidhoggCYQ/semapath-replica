# 数据连接与跨表分析

## 本轮目标

按 0.2.19 的 MySQL 入口，接入连接测试、加密凭据、表结构、预览、受限只读查询；PostgreSQL 与旧 duckdb 连接保留明确不支持状态。新增跨表执行把两个已登记工作表按显式键关联为快照，接入已有九方法、十四图型、问题框架和报告。

## 执行与依据

SQL 请求仅接受单条 SELECT / WITH SELECT 和受支持的常用只读函数；主进程检查语句、禁用多语句/LOCAL FILES、使用服务端只读事务。禁止注释、会话变量、文件访问、锁、延时、未知或数据库限定的函数调用。字符串采用两个单引号转义，会话固定 NO_BACKSLASH_ESCAPES。具备常用汇总、筛选、排序、子查询和简单 CTE；带显式列名表的 CTE 等不在当前保守语法子集内。

DECIMAL/BIGINT 以字符串读回，进入本地十进制引擎；FLOAT/DOUBLE 仍保留源库近似语义。一次查询最多 5000 行、40 个业务字段、4 MB 返回行数据；附加“结果行号”定位列。40 个业务字段与定位列可进入自然语言目录，关联时仍按总列数上限检查。连接超时 10 秒，服务端 SELECT 20 秒，上层数据库操作 30 秒，超限失败，不保存截断结果。显式 LIMIT 的含义完整保留在查询文本中，不能把受限结果当作整个业务库。

连接配置在 Windows 通过 Electron safeStorage/DPAPI 整体加密保存；不支持加密时不退回明文。密码不返回界面、任务或报告，编辑时未触碰密码沿用已保存值，输入新值后替换。连接按任务隔离，不能用另一个任务的连接 ID 读取、覆盖或删除。密文依赖当前系统用户的解密环境，不作为跨机器凭据备份。

查询结果保存为不可改写的工作簿快照，保留查询、数据库、连接名称、取数时间、服务端版本、字段类型、完整返回值与文件 SHA-256。结果行号是本次查询的定位信息，并非数据库业务主键；需要主键时应在 SELECT 中显式选择真实主键。重新查询产生新快照，避免把变化后的数据库当作历史结果。零行查询保存明确的空快照，后续计算明确报无可计算记录。

跨表支持 left / inner、多对一或一对一；核对右侧唯一键，一对一同时核对左侧，拒绝重复导致的数值膨胀。文本键精确区分前导零、大小写及空格；数值键显式采用十进制规范化。缺失键互不匹配，保留缺失/未匹配统计，不强行补值。每侧最多 2000 个非空记录、总计 40 列、8 个原始来源、12 个连续步骤；不支持会产生歧义的同源不同记录自关联。

跨表快照保存父文件 SHA、列映射、原始行及其单元格值。SQL 父来源还保存查询全文、完整返回值、取数时间和字段类型。连续关联会展平到原始来源，保留全部步骤；数值、分组和筛选字段能定位原表单元格。Excel 日期按工作簿日期系统转换为 ISO 日期用于关联后的日期分析，同时冻结原来的日期序列值。父文件后续变化不改写已有快照，重新关联才得到新版本。

分析、图形、发布与报告复用现有计算引擎。/4 报告冻结所有 SQL 结果、关联映射与计算输入；A4/16:9 PDF 展示取数时间、SQL、源文件指纹、关联键/关系/方式和原始单元格定位示例。原始文件后来被移除也不影响已发布内容导出；旧 /1–/3 报告仍可读取。报告依据同时检查父引用、行/列映射和原始值的一致性。

## 交互

BEFORE: 数据连接 → 文件/Excel；SQL 为待开发提示。
AFTER: 数据连接 → MySQL 配置/测试/表结构/预览/查询并登记快照；
       文件/Excel → 两表、表头、键、关系与关联方式 → 生成关联快照；
       分析/依据/发布/报告沿用现有工作台。

界面继承现有 Operate 字体、蓝色、浅深色主题与线性布局，无新的视觉世界。连接、查询、取消、错误和空结果在相应操作附近表达，不添加独立装饰页。

## 使用步骤

1. 新建任务 → 连接数据/管理连接 → SQL 数据库。填写 MySQL 主机、端口、数据库、账号和密码，按环境选择是否启用 TLS 证书验证。
2. 测试并保存连接，读取表结构，选表并预览。预览只显示最多 50 行，不作为分析依据。
3. 填写快照名称，确认 SELECT 查询及范围，执行“执行并登记结果快照”。成功后该结果出现在任务文件的数据源列表中。
4. 若需要跨表，先将另一份 Excel/CSV 或 SQL 结果登记到同一任务。在文件/Excel 连接入口展开“跨表关联”，选择两边的表头和键、关系、关联方式、键解释及快照名称，生成关联数据源。
5. 在“分析工作”中直接提问已有查询快照或关联快照，也可使用手动计算与九种方法。选择已配置的聊天模型，检查数字和图表的数据依据后发布，并在“报告与成果”生成 A4/16:9 报告。

自然语言分析现可在“自动读取连接数据”中选择当前任务连接，由模型读取真实结构、生成只读 SQL，并在业务关系明确时与选中的文件关联，再进入本地完整计算和复核。手动查询／关联路径保持可用。自动 SQL 另有基于 AST 的当前数据库／已知表范围限制，并保守拒绝 CTE。范围和使用见 [自然语言取数](natural-data.md)。原版开放式代码 Agent、自由业务图和全部报告模板仍在后续范围。Power BI 真实 PBIX/账号/权限/XMLA 仍待联测，见 [Power BI 连接](powerbi.md)。当前报告为 /6，继续保留本页所述 /4 的 SQL/关联依据并读取旧冻结成果。

## 验证边界

本机 MySQL 可执行程序仅用于缓存目录中的独立临时实例，不触碰已有服务或数据。通过真实 SQL 协议验证精度、只读事务、结果上限、鉴权、服务端超时、取消及继续读取；真实 Electron 验证连接加密、重启恢复、关联/自然语言链路与 PDF。模型回答使用明确标注的本地合成 HTTP 响应，不是实际业务模型质量验收。

真实用户库、TLS 证书环境、服务器版本兼容矩阵与 Power BI 账号另行验收。当前会话 SQL 选项要求兼容的 MySQL 服务端，不将 MariaDB、PostgreSQL 或旧 duckdb 连接标为完成。取消会销毁本地连接；服务端耗时计算可能到达执行时限后才停止。进入快照保存阶段后不再接受取消，以避免已保存结果被误报为取消。
