# 自然语言文件分析与自动取数

## 用户路径与模型配置

启动开发版，新建任务并添加 Excel/CSV，在“分析工作”的“直接提问分析数据”中选择聊天模型并提问。也可选择“自动读取连接数据”，在任务已有 MySQL／Power BI 连接上直接提问，操作与边界见 [自然语言取数](natural-data.md)。原有“手动计算”保持独立可用。模型未配置时显示配置入口和刷新按钮；不会以预置关键词答案替代模型。

配置复用现有“模型与应用设置”：添加模型服务，填写服务要求的地址/凭据，启用聊天模型，返回分析页刷新并选择。支持现有 ProviderRuntime 能处理的聊天模型适配器；ACP、向量、图片、语音和视频模型不进入分析模型列表。接口错误、额度、上下文不足会明确报错并保留问题。

可尝试的问题（字段名称须以实际工作簿为准）：

- 按区域汇总销售额，找出最高的区域并画图。
- 只看华东和华南，计算每个区域的销售额占比。
- 筛选 2026 年 1 月到 3 月的数据，按月展示销售额趋势。
- 对比华东今年与去年同期的销售额，给出差额与增幅。
- 继续追问“只看华东呢？”或回答上一轮要求补充的字段。

每次询问使用当前绑定版本重新读取文件。最近 4 轮所选分支的问题、计划及澄清进入模型上下文；界面保留全部已保存记录。选择历史提问后继续会创建显式父子分支；新建问题开始新的根路径。

## 执行与依据

1. 从当前任务绑定文件提取工作表、原始列字母、表头候选、格式和有限样本；核对 SHA-256。添加文件本身不会请求模型。
2. 所选聊天模型生成严格 JSON 计划，明确来源、工作表、表头、度量、分组、筛选、运算和视图。校验拒绝未知字段、其他任务来源、无效列和不支持的口径；不能返回或执行任意代码。
3. 独立 Worker 对完整已绑定版本执行本地计算，记录每项结果的精确分子/分母、筛选、原始行和单元格。
4. 同一所选模型根据实际执行结果复核，可确认、请求澄清，或修正一次计划后重新计算。JSON 结构错误允许有限重试，整个任务最多 4 次模型调用；未确认的结果不保存为数字回答。
5. 本地依据生成回答与图表。模型不能写入数值结论或图表数据。排名使用精确比较；占比、差额和增幅使用十进制/有理数计算，分数展示最多 12 位小数。
6. 整次保存问题、计划、模型、复核状态、所有运行记录和派生依据。发布时复核回答内容 hash、关联运行 hash、绑定与实际源文件 SHA-256；一个来源失效即不发布半份回答。

点击原始结果或图形进入数据依据，可见原文件、工作表、文件指纹、计算口径、输入行和单元格。点击占比/差额/增幅进入派生依据，显示公式、精确表达式及每个输入结果，再点击输入继续追溯原始行。图表和回答共用相同结果 ID。

源文件改动会阻止重新分析或发布旧版本；在“任务文件”点击“更新文件版本”后重新提问。历史正式回答保留当时依据与指纹，不随文件刷新改写。

## 运算口径与资源边界

- 求和、平均、记录数、最小值、最大值。记录数为匹配条件的非空记录数；中位数和分位数通过分层方法计算，相关系数通过相关方法计算。非空度量计数、去重计数、预测、跨表联接和任意代码不在当前范围，需澄清或明确不支持。
- 筛选条件按 AND 组合；同一列 OR 采用显式集合。文本、数值、日期明确区分；空值不匹配数值比较。日期支持 Excel 日期格式数值（含 1904 系统）、ISO、斜杠和中文年月日文本，不猜测无日期格式的普通数字。
- 支持按日/月分组及升降序，排名最多展示 20 项。占比只对非负分组的求和/计数总和定义；零分母不伪造比例。
- 对比要求同文件、同度量、同运算与分组以及相同分组集合，不自动补零或跨文件拼接。基期 0 的增幅显示“无法定义”。原表单位保留，不自动换算。
- 基础视图为条形、折线和表格；新增方法视图支持九种方法与十四种图型，详见 [分析方法与图表](methods-and-charts.md)。超出 JavaScript 图形坐标表示范围的精确数字完整保留在表格中。
- 每轮最多 6 个来源、6 个查询和 8 个视图；每文件最多 20 个工作表、40 列用于模型结构分析，每表最多提供开头 12 行样本，样本文本每格最多 160 字符。样本边界不截断实际计算数据，表头不在样本范围时需整理数据或走手动入口。
- 提示词字符上限与所选模型上下文同时校验；上下文不足明确失败，不以部分结果充当完整回答。文件/行/分组/Worker 限制沿用 [Excel 规则](excel-chain.md)。
- 单次分析最长 180 秒，包含模型计划、计算与复核。停止按钮会取消模型传输及正在等待/执行的分析 Worker，保留输入问题，不留下半份记录；关闭来源窗口或应用也会中止相应任务。底层 Provider 若无法及时响应信号，仍受未完成请求并发限制约束。

模型请求包含问题、有限历史、字段/样本和本次分析结果，不包含应用原生路径或模型密钥。计算在本地执行；矩阵、相关和指标分解等方法的复核结果可能包含完整的逐对象数值和标识，不仅是汇总值。模型服务能接收到这些发送的字段、样本和结果，应按实际数据使用已配置的服务。

## 实现与验证入口

共享 Zod 合约：`src/shared/analysis.ts`；类型化 IPC：`src/shared/contracts/routes/analysis.routes.ts`。主流程：`src/main/analysis/naturalAnalyzer.ts`；模型桥：`modelGateway.ts`；计划/复核提示：`naturalPrompts.ts`；派生运算：`naturalFacts.ts`。界面：`NaturalChat.vue`、`NaturalAnswer.vue`、`NaturalDerivedEvidence.vue`。

回归：`scripts/replica.ps1 test test/main/analysis`。桌面端：`scripts/replica.ps1 e2e`，其中 03 使用本地合成 OpenAI 兼容 HTTP 服务，通过真实 ProviderRuntime、IPC、Worker 和界面执行。该测试验证协议、计算与依据链路，不替代真实模型语义准确率评测。开发版不内置该测试服务，也不会在正常运行时连接它。

完整原版开放式 Agent、任意 Python/代码分析、完整自由业务图和高级图表配置、原版完整报告模板与协议仍是后续范围。MySQL、Power BI 只读连接／快照和有边界的自然语言取数已接入；真实模型语义与微软环境另行验收。
已发布自然语言回答现可从旁边的“生成 PDF 报告”进入成果中心，导出整份已发布视图及来源。详见 [报告与成果](reports.md)。
## 保存的问题框架与分支

当前已支持可选 frame 和逐问题判断，数字由实际依据引用展示；根问题、子问题和兄弟分支在“分析业务图”中选择。显式父链只传该分支最近历史，开始新问题清空其他分支上下文；旧 API 无显式上下文时保留既有历史兼容。

选择查询口径下钻后，后续结果固定同一源版本、工作表、表头和父筛选。数值输入下钻固定为该值实际使用的行，不能自动包含未参与计算的空值记录。每次递归保留最近查询新增的条件；多条查询口径不同应选择具体查询。受控分支只描述所选源，不因无关工作簿失效而失败。

模型解释与数据事实分别展示，不把计算确认当作假设成立。详细合同、恢复与报告范围见 analysis-framework.md。
