# 服装门店模拟账本

`clothing-store-sample.xlsx` 是完全虚构的2026年10月服装门店数据，不含真实客户、员工或供应商资料。

包含商品档案24行、期初库存24行、批发进货72行、零售账单513行、退货记录32行、经营费用12行；零售账单对应360笔原始订单。首行为表头，金额为人民币，SKU成本固定，退货按原成交价退回可售库存，采购及费用均已支付。

安装应用后，新建任务并添加此Excel。基础核对无需模型：

1. 在手动计算入口选择“零售账单”，对“实收金额(元)”求和，应为129,389.30元；按SKU或日期分组可查看组成和趋势。
2. 选择“退货记录”，对“退款金额(元)”求和，应为6,630.25元。
3. 选择“经营费用”，对“金额(元)”求和，应为25,150.00元。
4. 依次点击结果数值核对输入单元格，发布正式结果后尝试报告导出。

净销售额为122,759.05元。完整跨表案例另通过专门业务脚本执行成本、退货、库存和经营口径，并完成107项数值独立核对；不能把这段脚本处理描述为已内置完成的服装进销存模块。自然语言自动分析需要用户配置支持相应调用方式的模型，真实模型理解质量仍需业务验收。
